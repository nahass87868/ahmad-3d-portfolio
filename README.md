# Ahmad 3D Portfolio

Static portfolio website for Ahmad Nahass.

- Dark mode is the default.
- Header sun/moon toggle switches between dark and light mode.
- Theme choice is saved in the browser.
- Projects support multiple images and optional MP4 video.
- `Realistic Ice Render` is included under `Product Visualization`.

Upload the complete folder to Cloudflare Pages with `index.html` at the root. Keep `images/` and `videos/` beside the HTML/CSS/JS files.
